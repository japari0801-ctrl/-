1. Firebase에서 원본 설정 복사

Firebase 콘솔 → 프로젝트 설정 → 일반 → 아래쪽 내 앱 → 자파리 웹앱 → SDK 설정 및 구성 → 구성(Config) 선택 → 오른쪽 복사 버튼을 누르세요.

`const firebaseConfig = { ... };` 전체를 그대로 붙여넣습니다. npm 명령어나 `initializeApp` 부분은 있어도 무관합니다. 서비스 계정 비공개 키나 관리자 비밀번호는 붙여넣지 마세요.

설정을 붙여넣고 ‘연결 확인’을 눌러주세요. 이 페이지는 기존 firebase-config.js 파일을 읽지 않습니다.
